# Day 7 - Python Lists

A beginner-friendly Python practice project focused on creating, accessing, updating, and managing lists.

## Topics Covered

- Creating empty, mixed, and multi-item lists
- Accessing items with indexing and negative indexing
- Slicing lists using positive and negative indexes
- Unpacking list items using `*rest`
- Modifying items and checking values using `in`
- Adding items with `append()`, `insert()`, and `extend()`
- Removing items with `remove()`, `pop()`, `del`, and `clear()`
- Copying, joining, counting, and finding items using `copy()`, `+`, `join()`, `count()`, and `index()`
- Sorting and reversing with `sort()`, `sorted()`, and `reverse()`
- Finding min, max, median, average, and range of a list

## Technologies Used

- Python 3

## How to Run

```bash
python day7.py
```

## Learning Outcome

Practiced managing ordered data using lists and learned how to access, slice, modify, sort, and remove items.
