# Day 6 - Python Dictionaries

A beginner-friendly Python practice project focused on creating, accessing, updating, and managing dictionaries.

## Topics Covered

- Creating dictionaries and accessing key-value pairs
- Finding dictionary length using `len()`
- Accessing values with keys and `get()`
- Adding and updating dictionary items
- Checking keys using `in`
- Copying dictionaries using `copy()`
- Removing items with `pop()`, `popitem()`, and `del`
- Retrieving keys, values, and items
- Converting dictionary data into lists
- Working with nested data types, including lists inside dictionaries

## Technologies Used

- Python 3

## How to Run

```bash
python day6.py
```

## Learning Outcome

Practiced managing structured data using dictionaries and learned how to add, modify, access, and remove key-value pairs.
